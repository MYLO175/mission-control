# Reuse and publication

This initial private repository is maintained by MYLO175. The foundation adapts provider code from the creator's 3PO project; the pinned reference and manifest record its source.

No broad open-source licence is attached to this initial private version. Choose the intended reuse terms when preparing a public release. Keep personal apps, customer specifications and credentials in their own locations. Making the starter public is a separate owner decision from publishing new commits to this private repository.
