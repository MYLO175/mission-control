## Reading the guides

The product and architecture guides describe implemented behaviour and its limits. A source-free fixture, signed build, installation and sustained real-world reliability establish different things; the [verification tiers](development/DEVELOPMENT.md#choose-the-right-checks) explain those distinctions.

Examples use fictional data. Personal source content, credentials and diagnostic captures stay outside the repository. These Markdown pages and diagrams can be read directly on GitHub or in a local editor.
