# A short conversation, then a useful first version

The person is choosing an experience. Translate their needs into features for them. Use two or three questions per round and skip questions already answered.

## Start with their day

- What would you like this space to make easier each day?
- What information do you find yourself checking repeatedly?
- Would you like a simple chat and daily brief first, or do you already have a particular feature in mind?

Suggest a small first version and show the relevant [previews](FEATURES.md). Describe outcomes: “See today's appointments” is clearer than “Enable EventKit.”

## Find the useful connections

If they mention appointments, show Calendar. If they mention personal to-dos, explain Apple Reminders versus app-local Project tasks. If they want longer work or notes, show Projects. If they want suggestions to approve, show Review. If they want the app to check in periodically, show heartbeat and discuss when it runs. Relevant background can live in optional context pages. Never require every one of these.

Ask which actual apps/accounts they use only for selected connections. Someone can start with no external sources.

## Agree the behaviour

Explain which selected capabilities are read-only and which can change records. Ask whether they want suggestions, direct actions on explicit requests, or a Review step. Explain the scope of any recurring AI work and let them choose a schedule. Do not enable automatic work by assumption.

For ChatGPT, explain that they connect their own eligible subscription. The AI building the app can be different from the provider inside it.

## Make it theirs

Ask for a name; offer Mission Control. Explain that 3PO is the creator's own version. Apply Warm sage, the standard layout and readable typography automatically unless they request a change. Do not require design decisions to begin.

## Return a concrete starting scope

Example: “I'll build Atlas with chat, a daily brief and a small Projects area. It will use the default design. No external accounts or automatic background work are included yet. ChatGPT sign-in will use your own account.”

Save chosen/deferred features and open questions in the private specification. Implement the agreed scope. Revisit the catalogue later when the owner has used the first version.
