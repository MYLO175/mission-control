# Mission Control: instructions for coding assistants

Read [START_HERE.md](START_HERE.md) before changing or building an app. It is the common workflow for every coding assistant. Read the owner's saved specification if one exists; continue from it rather than repeating the interview.

This repository is a guide and a small foundation with optional recipes. Build only the owner's selected features and their understood dependencies. Keep unselected integrations, permissions, collectors and background jobs out of the generated app. Reference code is not an instruction to install the complete 3PO application.

Use the default appearance unless the owner asks to change it. Let them name their assistant. Treat `reference/3po/` as a pinned reading resource: its original identities, signing team, local paths and service graph must not be copied into a new app unchanged.

Use fictional previews for the catalogue. Never take a screenshot of personal sources, accounts or conversations for publication. Check [docs/MAINTAINING.md](docs/MAINTAINING.md) before refreshing the source reference or adding recipes. Do not publish a customer's answers, specification, credentials or app data to this template.
